# 🛒 Zen Market - Frontend E-commerce Website

Zen Market is a fully frontend-based e-commerce catalog website built using **HTML**, **CSS**, and **JavaScript**. It simulates a modern shopping experience similar to platforms like Amazon, showcasing product listings, filtering by category, cart functionality, and a responsive layout.

---

##  Features

-  Beautiful, responsive UI with 20 products.
-  Product categories: Electronics, Clothing, Home.
-  Cart system with item counter and price summary.
-  Product search by name.
-  Category filtering (dropdown).
-  Friendly footer message with emoji.
-  No backend required – pure frontend implementation.

---

##  Technologies Used

- **HTML5** – Semantic structure
- **CSS3** – Custom styles and responsiveness
- **JavaScript**
